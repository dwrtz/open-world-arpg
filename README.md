# Wylden

A mobile-first, open-world mining ARPG. Explore a persistent world, carve through material terrain, discover underground biomes, and turn rare finds into equipment and synergistic character builds.

Craft at stations in the world and manage gear through contextual overlays. Direct pixel art, responsive combat, and organic geography define the experience.

## Development

The project is in design and prototyping. [World Forge](https://wylden-world-forge.dwrtz.chatgpt.site) is an owner-private experiment in organic, hierarchical terrain generation and digging.

Target: a game engine delivering to mobile and desktop browsers through WebAssembly/WebGPU. Bevy/Rust is the leading candidate, pending real-device validation. Builds run in project-controlled CI or development environments; Userland is the intended deployment platform.
