# Decisions and next proofs

## Selected direction

- Persistent open-world mining ARPG with crafting and equipment management in the world.
- Orthographic side-view presentation using Blender-authored 3D characters and environments.
- Composable, parametric models with shared rigs, modular equipment, independent appearance controls, and attached effects.
- Fine-scale material terrain and organic, hierarchical whole-world generation.
- WFC for useful local constraints within the hierarchy; continuous geography across logical regions.
- Many visually distinct biomes within a coherent art style.
- Project-owned builds; Userland deployment with content-addressed artifact reuse.

## Next proofs

- **Assets and rendering:** engine export, runtime character assembly, equipment swaps, animation, effects, and lighting.
- **World:** character traversal, chunk seams, persistent mining, and selected material behaviors.
- **Mobile:** touch feel, readability, frame time, memory, and lifecycle recovery on real devices.

## Open choices

Engine/version, export conventions, and browser support floor; lighting and performance budgets; detailed simulation rules; death/recovery and overlay pause behavior; online progression authority; code and asset licenses.

Use short numbered decision records when a consequential technical choice is settled: decision, rationale, evidence, and consequences.
